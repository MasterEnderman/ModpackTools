# Modpack Tools

A collection of python projects I wrote while working on various Minecraft modpacks.

## Projects

- [PaletteCreator](https://github.com/MasterEnderman/ModpackTools/blob/master/PaletteCreator/)
- [PaletteMixer](https://github.com/MasterEnderman/ModpackTools/blob/master/PaletteMixer/)
- [PngBlender](https://github.com/MasterEnderman/ModpackTools/blob/master/PngBlender/)
- [PngBlender2](https://github.com/MasterEnderman/ModpackTools/blob/master/PngBlender2/)

# Usage

Every project utilizes [uv](https://github.com/astral-sh/uv) for dependency management.

```bash
cd <project-name>
uv sync
uv run <project-name> <args>
```
